# 01-s3-private

Primeiro laboratório em Terraform: um bucket S3 privado, criptografado e com o acesso público bloqueado.

## Arquivos

| Arquivo | Para quê |
| --- | --- |
| `versions.tf` | versão do Terraform e do provider da AWS |
| `providers.tf` | configuração do provider e das tags padrão |
| `variables.tf` | entradas do laboratório |
| `main.tf` | os recursos (a escrever) |
| `outputs.tf` | valores mostrados ao final (a escrever) |

## Como rodar

```
terraform init
terraform fmt
terraform validate
terraform plan
terraform apply
terraform destroy
```

Leia o `plan` linha por linha antes do `apply`. No fim, sempre `destroy`.
