# Cloudlab

A cloud infrastructure lab built as a study project to learn cloud architecture with a security mindset, on the way to a career in cybersecurity.

Each lab builds a small piece of infrastructure on AWS with Terraform, then secures it, monitors it and tears it down. Nothing here is production-ready, and nothing replaces a real security review.

The idea, approach and roadmap live in [learning/](learning/) (in portuguese).
